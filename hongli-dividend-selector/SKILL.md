# 银月红利精选指数选股系统

> 持股收息，构建自己的红利指数。

---

## 执行规则（最重要）

**此Skill激活后，执行以下流程：**

1. **首先读取本skill下的 references/framework.md**，加载完整的选股框架和评级标准
2. **调用妙想 skill（mx-xuangu 全市场初筛 → mx-data 逐只补查）** 获取数据
3. 按四层漏斗逐步筛选，生成选股结果
4. 输出完整报告：持仓列表 + 各股评分 + 组合数据

## 选股框架总览（四层漏斗）

### 第一层 · 一票否决（硬性剔除）
有一条不满足即排除：
- 非 ST、*ST、退市风险警示
- 近 3 年审计意见为"标准无保留"
- 近 3 年无重大财务造假/严重违规处罚
- 行业非强周期顶部、非高杠杆危险区

### 第二层 · 量化门槛（必须全部满足）

| 维度 | 指标 | 门槛 |
|------|------|------|
| **股息** | 连续现金分红年限 | ≥ 5 年 |
| | 近 3 年平均股利支付率 | ≤ 100%（仅限制不超过100%，不设下限） |
| | 最近 12 个月股息率 | ≥ 4.0% 且 ≥ 2 倍 10 年国债收益率 |
| | 分红稳定性 | 近 5 年任何单年同比下降 ≤ 20% |
| **财务安全** | 资产负债率 | < 70%（金融股放宽至 < 95%） |
| | 经营现金流 / 净利润 | 连续 3 年 > 80% |
| **盈利能力** | ROE（净资产收益率） | 连续 3 年 ≥ 10% |
| | 毛利率 | > 20% |

> 如果 2 倍国债收益率的计算结果低于 4.0%，以 4.0% 为实际门槛

### 第三层 · 行业与地位约束

**优先行业**（按盈利稳定性排序）：
稳定消费 > 公用事业 > 医药健康 > 金融（非高杠杆） > 先进制造 > 能源/交运

**地位要求**：
- 细分行业龙头或前三（按营收/市值排名）
- 市值 > 100 亿
- 日均成交额 > 5000 万

**分散约束**：
- **每行业最多入选 2 只**（按评分从高到低，同一行业只保留评分最高的 2 只）
- 单行业权重 ≤ 20%
- 单只个股权重 ≤ 10%（股息率加权但有硬上限）
- **组合数量上限**：按综合评分取 TOP 10，不足10只则全部纳入

### 第四层 · 五维综合评分

**权重分配**：

| 维度 | 权重 | 评分逻辑 |
|:----:|:----:|----------|
| 🥇 股息率 | 25% | 越高越好，≥ 8% 满分，< 3% 0 分 |
| 🥇 财务质量 | 20% | ROE × 40% + 负债率 × 30% + 现金流 × 30% |
| 🥇 估值 | 25% | PE/PB 历史百分位，低位高分、高位低分 |
| 📈 稳定成长 | 15% | 近 3 年净利润复合增速 + 营收稳定性 |
| 🛡️ 竞争力 | 15% | 毛利率水平 + 行业排名 + 护城河定性判断 |

按总分从高到低排序，取 TOP 10 只构建组合。若通过前3层筛选的股票不足10只，则全部纳入。

## 权重计算方式

**评分加权**（主人指定）：
- 每只股票权重 = (个股综合评分 ÷ 所有入选股票综合评分之和) × 100%
- 单只上限 10%
- 单行业上限 20%

**约束调整逻辑（必须严格执行）**：
1. 计算原始权重后，检查是否有股票超10%上限
2. 若有，找出原始权重最高的股票 Wmax
3. 计算压缩因子 = 10% ÷ Wmax（即最高那只刚好压到10%）
4. **所有股票的最终权重 = 原始权重 × 压缩因子**
5. 检查单行业是否超20%，若超则行业内等比例压缩

**这种方式的优点**：
- 格力电器（评分最高）最终权重 = 10%（满配）✅
- 西藏药业（评分第二） = 约9.2%
- 伟星新材（评分最低） = 约8.0%
- 优股多配，评分高的股票获得更多资金

> 🚫 注意：禁止将超10%的股票全部"拍平"到10%等权重，这会让评分加权失效。

**组合整体股息率验证**：
```
组合股息率 = Σ(个股股息率 × 个股归一化权重)
```
- **个股权重**：指压缩后各股票在"买入资金池"中的比例，而非占总仓位的比例
- **归一化方法**：个股归一化权重 = 个股最终权重 ÷ Σ(所有入选股最终权重)
- **举例**：格力最终权重5.00%，总仓位37.01%，则格力归一化权重 = 5.00% ÷ 37.01% ≈ 13.51%
- 组合加权股息率应接近入选股票的平均股息率（4.0% - 7%），低于4.0%说明选池偏弱
- ⚠️ **不要用总仓位（含现金）作为分母计算**，现金不产生股息

## 组合管理规则

| 项目 | 规则 |
|------|------|
| 持仓数量 | TOP 10（通过评分后取前10，不足10只全部纳入）<br>同一行业最多保留评分最高的 2 只 |
| 权重方式 | 股息率加权 |
| 调仓频率 | 每季度一次（年报4月底 + 半年报8月底 + 三季报10月底） |
| 单只上限 | ≤ 总仓位 10% |
| 单行业上限 | ≤ 总仓位 20% |
| 换手率限制 | 单次调仓换股 ≤ 30% |
| 卖出/减仓条件 | 见下方详细规则 |

### 卖出/减仓规则

**无条件卖出（必须清仓）**：
- 股息率跌破 2.5%（股价大涨透支股息）
- ROE 连续 2 年 < 8%
- 出现财务风险信号（审计非标、ST警示、重大违规处罚）
- 触发一票否决中的任何一项

**条件性减仓（降低权重）**：
- 单行业超 20% 上限 → 按股息率从低到高依次减仓，直至达标
- 某只股票因股价大涨导致股息率降至 3%-4.0%区间 → 减半仓
- 某行业基本面恶化（政策打压、需求下滑）→ 该行业所有股票减至半仓

**定期调仓时的减仓流程**：
1. 先检查现有持仓中哪些触发了卖出条件 → 列为**强制调出**
2. 再检查需要减仓的股票及减仓幅度 → 列为**建议减仓**
3. 释放的资金用于买入新入选的股票
4. 换手率不超过 30%，优先执行强制调出

#### 第1步：mx-xuangu 多条件初筛（仅需1次API调用）

**命令**：
```bash
mx_xuangu.py "股息率TTM大于4.0% 资产负债率小于70% 毛利率大于20% 的A股 列出代码 名称 股息率TTM 资产负债率 毛利率 净利润现金含量 股利支付率 审计意见 市盈率百分位 行业"
```

> ⚠️ **实测发现**：添加"行业"关键词后，API返回的数据量会增加（从~106只增加到~150只）。这是因为"行业"关键词触发了不同的API解析分支，可能会放宽部分筛选条件。**建议以列出"行业"的版本为准**，多出来的股票可以在后面用mx-data复核。

**筛选条件说明**：
- ✅ **股息率TTM>4.0%** — 使用TTM口径（最近12个月分红÷当前股价），与门槛"最近12个月股息率"一致
- ✅ 注意：**mx-xuangu的"股息率TTM"和"年度股息率"是两个不同字段**，必须用TTM。年度股息率可能偏低（只含一次分红）
- ✅ **资产负债率<70%** — 最新数据，季度影响很小，可用
- ✅ **毛利率>20%** — 最新数据，季度影响较小，可用
- ❌ **不筛ROE** — mx-xuangu只能查最新一期ROE（一季报），严重失真。实测加ROE>10%条件后106只骤降至4只（如格力电器被剔除），可见季度ROE严重偏低。必须用mx-data查年报ROE
- ❌ **不筛净现比** — mx-xuangu返回的净利润现金含量是季度数据，不能用于评分

**mx-xuangu 一次返回的字段**（2026-05-15实测）：

| 字段 | 数据来源 | 是否可直接用 |
|:-----|:---------|:------------|
| 股息率TTM | ✅ **TTM口径** | **推荐使用！** 包含近12个月所有分红 |
| 资产负债率(%) | ⚠️ 最新季度 | 季度影响小，可直接用于初筛 |
| 销售毛利率(%) | ⚠️ 最新季度 | 季度影响小，可直接用于初筛 |
| 净利润现金含量(%) | ⚠️ 最新季度 | 🚫 **仅作初筛参考，严禁用于评分** |
| 股利支付率(报告期)(%) | ⚠️ 最新报告期 | 初筛参考，mx-data复核 |
| 审计意见类别 最新年报 | ✅ **年报数据** | 直接用于一票否决 |
| 市盈率百分位(%) | ✅ 日频数据 | 直接用于五维评分 |
| 市盈率(动)(倍) | ✅ 实时 | 直接用于五维评分 |
| 市盈率(TTM)(倍) | ✅ 实时 | 直接用于五维评分 |
| 市净率(倍) | ✅ 实时 | 直接用于五维评分 |
| 总市值(元) | ✅ 实时 | 直接用于筛选（>100亿） |
| 流通市值(元) | ✅ 实时 | 辅助参考 |
| **东财行业分类二级** | ✅ 分类固定 | ✅ **可直接用于行业约束**（查询需含"行业"关键词） |
| **东财行业总分类** | ✅ 分类固定 | ✅ 辅助参考 |
| **申万行业分类** | ✅ 分类固定 | ✅ 辅助参考 |

**新增字段实测说明**：
- 查询中加入"行业"关键词后，API额外返回 `东财行业分类二级`、`东财行业总分类`、`申万行业分类`、`概念` 等字段
- 行业分类可直接用于第三层"每行业最多2只"的约束判断
- **建议优先使用"东财行业分类二级"**，粒度适中，避免分类过粗或过细

**效果**：约筛出 **100-150 只**候选股，同时带回大部分评分所需的指标和行业信息。

**银行股特殊处理**：如需纳入银行，单独执行
```bash
mx_xuangu.py "股息率TTM大于4.0% 资产负债率小于95% 的银行股 列出代码 名称 股息率TTM 资产负债率 净利润现金含量 股利支付率 审计意见 市盈率百分位"
```

#### 第2步：mx-data 补查 ROE 和分红数据（约20-30次API调用）

对第1步筛出的候选股，**先用 mx-xuangu 的季度数据做个初步评估**，对大概率通过的股票，用 mx-data 补查年报维度的关键数据：

| 补查数据 | mx-data查询方式 | 原因 |
|:---------|:---------------|:-----|
| **ROE（年报）** | `"查询[代码]2023-2025年报ROE"` | mx-xuangu只有季度ROE，失真，必须年报，一次查3年 |
| **净利润现金含量（年报复核）** | `"查询[代码]2023-2025年报 经营活动产生的现金流量净额/净利润"` | 直接返回计算好的净现比，无需手动计算 |
| **股利支付率（年报）** | `"查询[代码]2023-2025年报股利支付率"` | 核实季度数据，一次查3年 |
| **每股分红（近5年）** | `"查询[代码]近5年每股分红"` | 验证连续分红+稳定性 |
| **行业分类** | `"查询[代码]所属行业"` | 用于行业约束验证 |

**ROE年报数据处理规则**（⚠️ 最重要的规则之一）：
- 必须使用**最新年报**及前两年的ROE数据（共3年），建议一次查3年：`"2023-2025年报ROE"`
- 禁止使用任何季报、半年报的 ROE 数据
- 如果查询不到年报 ROE，检查数据是否标注为"加权净资产收益率ROE(加权)(%)"
- 如果最新年报数据获取失败，降级使用前一年年报

**现金流（净现比）强制规则**（⚠️ 最重要的规则之二，与ROE同等重要）：
- 🚫 **严禁使用 mx-xuangu 季度"净利润现金含量"数据进行评分**
- ✅ 必须用 mx-data 查询年报的 **"经营活动产生的现金流量净额/净利润"** 字段，直接返回计算好的净现比
- ✅ 查询语法：`"查询[代码]2023-2025年报 经营活动产生的现金流量净额/净利润"`
- ✅ 返回示例：`2025年报=160.7%`，直接用于评分，**无需手动计算**
- ✅ 要求：连续3年（2023/2024/2025）每年净现比均 ≥ 80%
- ✅ 任一一年低于80% → 直接剔除，无例外
- ⚠️ 季度数据仅用于初筛参考（排除明显负值），不得用于评分公式

**数据校验要点（对比季度 vs 年报的典型失真案例）**：
| 股票 | 季度净现比 | 年报净现比(2025) | 偏差 |
|:----:|:----------:|:----------------:|:----:|
| 达仁堂 | 99.6% | 21.8% | 差4.6倍 ❌ |
| 宇通客车 | 530% | 56.8% | 差9.3倍 ❌ |
| 索菲亚 | 736.9% | -34.1%(为负) | 符号都反了 ❌ |
| 泸州老窖 | 122.5% | 65.6% | 差1.9倍 ❌ |
| 海澜之家 | 166.5% | 210.2% | 差1.3倍 ⚠️ |
以上案例证明：**任何情况下都不得用季度现金流数据替代年报数据**。

**API调用估算**：
- 优化前：200次mx-data全量查询 ❌
- 优化后：**1次mx-xuangu + 约20-30次mx-data** = 21-31次 ✅（节省85%+）

### 步骤 2：逐层筛选
按四层漏斗依次过滤：

1. 剔除一票否决项
2. 应用量化门槛过滤
3. 行业约束
4. 五维评分排序，**取 TOP 10**（不足10只则全部纳入）

**注意**：评分排名的所有候选股（不仅前10）都必须在报告中列出，以供参考。但建仓方案只按前10只做。

**每行业最多2只的选入逻辑**：
按评分降序逐只检查，同一行业最多选入评分最高的 2 只，跳过已满额的行业，直至选满 10 只或遍历完所有候选股。

**⚠️ 遗漏校验 + 数据来源校验（必须执行）**：

**ROE数据校验（最重要）：**
- 逐只检查报告中的ROE数据是否来自**最新年报及前两年**（共3年）
- 如果ROE来源是最新一季报数据 → 必须重新用mx-data查询年报ROE
- ROE数据应标注"最新年报"，绝不允许标注"最新一季报"

**其他数据来源校验：**
- 股息率必须来自mx-xuangu的"股息率TTM"字段，或mx-data查询的"股息率(TTM)"字段
- 如果有任何一项数据是手动计算或用文章数据替代的 → 重新用妙想查，禁止编造

**现金流数据来源校验：**
- 新版查询语法 `"经营活动产生的现金流量净额/净利润"` + `"年报"` 关键词 → 返回即年报数据 ✅
- 校验方法：确认查询语句中包含了 `"年报"` 关键词（如 `"2023-2025年报"`）
- 如果没有 → 回到 mx-xuangu 的季度数据 → ❌ 拒绝使用，重新用含"年报"关键词的查询

**候选池完整性校验：**
- 用 mx-xuangu 再次查询全市场"股息率TTM > 4.0% 的A股"，核对候选池是否覆盖了所有高息股
- 如果 mx-xuangu 返回了N只候选股，但你只筛选了不到N/3只 → 说明遗漏严重，需要检查数据获取流程
- 知名高息白马股（如五粮液、招商银行、大秦铁路等）必须单独确认其股息率是否达标

### 步骤 3：加权计算
计算每只股票的股息率加权仓位，检查上限约束。

### 步骤 4：输出报告
输出包含以下内容的选股报告：

- **组合概览**：持仓数、组合股息率、单行业分布
- **持仓明细**：分成两张表——
  - **全量候选表**：列出所有通过前三层筛选的股票，**每只都必须包含完整的五维评分和综合评分**，即使未进入前10
  - **TOP 10 建仓表**：仅展示前10只的建仓方案
- **五维评分表**：独立展示所有候选股的评分明细（原始分+加权分+总分），格式：`原始分/加权分`
- **行业分布图**
- **具体建仓方案**：每只股票的具体购买比例（严格遵守单只≤5%、单行业≤20%约束），按实际可执行格式输出
- **行业集中度校验**：必须逐行业验证权重是否≤20%，超限则压缩
- **减仓/调出方案**（必须包含，逐只说明）：
  - 强制调出：触发卖出条件的股票及具体原因（哪项指标不达标、具体数值）
  - 建议减仓：权重偏高或股息率下降的股票及建议减仓幅度
  - 减仓优先级：按风险程度排序，优先处理风险最高的
  - 释放资金去向：减仓释放的资金如何分配
- **调仓建议**：本次调入/调出股及原因汇总
