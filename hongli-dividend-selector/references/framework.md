> 参考编制：中证红利指数、标普红利贵族、格雷厄姆防御型选股、巴菲特所有者导向
> 数据来源：妙想(mx-xuangu + mx-data)

## 一、第一层：一票否决（硬性剔除标准）

### 1.1 剔除条件

| 条件 | 数据来源 | 判定方式 |
|------|----------|----------|
| ST、*ST、退市风险警示 | mx-data 股票列表 | 股票名称含 ST/*ST 或风险警示标记 |
| 近 3 年审计意见非标准无保留 | 年报审计意见字段 | 查询连续 3 年审计意见类型 |
| 近 3 年重大财务造假/违规 | 证监会处罚公告 | 查询近 3 年行政处罚记录 |
| 行业风险 | 行业分类 | 强周期顶部行业、高杠杆危险行业、政策严厉压制行业 |

### 1.2 典型高风险行业

| 行业 | 风险类型 | 处理方式 |
|------|----------|----------|
| 房地产 | 高杠杆 + 政策压制 | 原则上排除 |
| 钢铁/煤炭/有色（强周期） | 盈利波动极大 | 谨慎对待，优先排除 |
| 券商/保险（高杠杆金融） | 负债率天然高 | 视具体公司，通常需放宽负债率标准 |
| 影视/传媒 | 盈利不稳定 | 谨慎对待 |

## 二、第二层：量化门槛（详细说明）

### 2.1 股息相关门槛

#### 连续分红年限 ≥ 5 年
- **数据来源**：查询每股分红（DPS）近 5 年数据
- **判定**：5 年中每一年都有分红记录（金额 > 0）
- **注意**：送转股不算分红，只看现金分红

#### 股利支付率 ≤ 100%（不设下限）
- **公式**：股利支付率 = 每股分红 ÷ 每股收益
- **数据来源**：查询近 3 年股利支付率，取平均值
- **下限**：不设下限，即使分红比例很低也可以纳入
- **上限 100%**：不超过100%，超过则说明分红不可持续（可能靠借债分红）

#### 股息率 ≥ 4.0% 且 ≥ 2 倍 10 年国债收益率
- **公式**：股息率（TTM）= 最近 12 个月每股分红 ÷ 当前股价
- **数据来源**：mx-xuangu（初筛）或 mx-data（查"股息率(TTM)"字段）
- **当前参考**：10 年国债收益率约 1.6%，2 倍为 3.2%
- **实际门槛**：取两者较高值，目前基准 4.0%
- **动态调整**：每季度检查国债收益率变化

#### 分红稳定性（方案 A）
- **条件**：近 5 年中，每股股息的任何一年相比前一年下降幅度不超过 20%
- **计算方法**：
  ```
  年下降率 = (当年DPS - 前一年DPS) ÷ 前一年DPS
  如果年下降率 < -20%，则剔除
  ```
- **说明**：允许分红增长（正增长不受限），但防"腰斩式"下降

### 2.2 财务安全门槛

#### 资产负债率 < 70%
- **公式**：资产负债率 = 总负债 ÷ 总资产
- **数据来源**：mx-data 资产负债率字段
- **金融股放宽**：银行、保险等金融股放宽至 < 95%
  - 判定方式：行业分类为"银行""保险""证券"等的公司

#### 经营现金流 / 净利润 > 80%（连续 3 年）
- **公式**：经营现金流 ÷ 净利润
- **数据来源**：现金流量表和利润表
- **要求**：近 3 年每年都 > 80%（而非平均值）
- **逻辑**：确保利润是"真金白银"，非应收账款或纸面利润

### 2.3 盈利能力门槛

#### ROE ≥ 10%（连续 3 年）
- **公式**：ROE = 净利润 ÷ 净资产（归属母公司）
- **数据来源**：mx-data ROE 字段
- **要求**：近 3 年每年 ROE 均 ≥ 10%
- **逻辑**：巴菲特最看重指标，代表公司"用股东的钱赚了多少钱"

#### 毛利率 > 20%
- **公式**：毛利率 = (营业收入 - 营业成本) ÷ 营业收入
- **数据来源**：mx-data 毛利率字段
- **要求**：近 3 年毛利率均 > 20%
- **逻辑**：毛利率高代表有定价权和竞争壁垒

## 三、第三层：行业约束（详细说明）

### 3.1 优先行业排序
按"盈利的稳定性和可预测性"排序：

| 优先级 | 行业类别 | 典型子行业 |
|:------:|----------|------------|
| ⭐ 最高 | 稳定消费 | 白酒/食品饮料/家电/日化 |
| ⭐⭐⭐ | 公用事业 | 电力/水务/燃气 |
| ⭐⭐⭐ | 医药健康 | 中药/医药流通/医疗器械 |
| ⭐⭐ | 金融（非高杠杆） | 银行（大行）/保险（龙头） |
| ⭐⭐ | 先进制造 | 机械/汽车零部件 |
| ⭐ | 能源/交运 | 煤炭/石油/高速公路/港口 |

### 3.2 行业地位评定

**龙头企业判定标准**（满足任一即可）：
1. 细分行业营收排名前 3
2. 细分行业市值排名前 3
3. 具有明显品牌优势/定价权（定性判断）

### 3.3 行业约束与行业分散

**每行业最多 2 只**（新规则）：
- 按五维评分从高到低，逐只检查候选股
- 同一行业最多选入评分最高的 2 只
- 选满 10 只即止（不足10只则全部纳入）

**跨行业覆盖**：
- 确保组合覆盖至少 **4 个以上行业**（2只/行业 × 5行业 可实现完全配置）
- 本规则可有效避免同一行业扎堆4-5只的情况
- 同时推高其他行业股票入池机会，增加行业多样性

### 3.4 分散约束

- **单行业 ≤ 20%**：按申万一级行业分类
- **跨行业对冲**：确保组合投资覆盖至少 4 个以上行业
- **组合数量**：按五维评分取 TOP 10 构建组合，不足10只则全部纳入

## 四、第四层：五维综合评分体系（详细评分标准）

### 4.1 股息率评分（权重 25%）

| 股息率区间 | 得分 | 备注 |
|:----------:|:----:|------|
| ≥ 8% | 100 | 极高息，注意甄别价值陷阱 |
| 6% - 8% | 80 | 高息优质区 |
| 5% - 6% | 60 | 良好 |
| 4.0% - 5% | 40 | 及格线上 |
| 3% - 4.0% | 20 | 偏低了，需注意能否维持门槛 |
| < 3% | 0 | 不及格 |

实际得分 = 基础分 × （股息率 ÷ 4.0%），不超过 100 分

### 4.2 财务质量评分（权重 20%）

由三个子项加权计算：

**ROE 评分（40%）**：

| ROE | 得分 |
|:---:|:----:|
| ≥ 20% | 100 |
| 15% - 20% | 80 |
| 10% - 15% | 60 |
| < 10% | 0 |

**负债率评分（30%）**：

| 资产负债率 | 得分 |
|:----------:|:----:|
| < 20% | 100 |
| 20% - 35% | 80 |
| 35% - 50% | 60 |
| 50% - 70% | 40 |
| ≥ 70% | 0（已在一票否决过滤掉） |

**现金流评分（30%）**：

| 经营现金流/净利润 | 得分 |
|:-----------------:|:----:|
| ≥ 120% | 100 |
| 100% - 120% | 80 |
| 80% - 100% | 60 |
| < 80% | 0 |

### 4.3 估值评分（权重 25%）

基于 PE 和 PB 的历史百分位：

| PE/PB 历史百分位 | 得分 |
|:----------------:|:----:|
| < 20%（极度低估） | 100 |
| 20% - 40%（低估） | 75 |
| 40% - 60%（合理） | 50 |
| 60% - 80%（偏贵） | 25 |
| > 80%（昂贵） | 0 |

最终估值分 = PE 百分位评分 × 50% + PB 百分位评分 × 50%

### 4.4 稳定成长评分（权重 15%）

**净利润复合增速（CAGR，60%）**：

| 近 3 年净利润 CAGR | 得分 |
|:------------------:|:----:|
| ≥ 15% | 100 |
| 8% - 15% | 75 |
| 0% - 8% | 50 |
| < 0%（负增长） | 0 |

**营收稳定性（40%）**：
- 近 5 年营收全部正增长 → 100 分
- 仅 1 年负增长（且幅度 < 10%）→ 60 分
- 有 1 年以上负增长 → 0 分

### 4.5 竞争力评分（权重 15%）

综合以下三方面：

**毛利率水平（40%）**：
- ≥ 60% → 100 分（顶级护城河，如茅台）
- 40% - 60% → 75 分
- 20% - 40% → 50 分（刚过门槛）

**行业排名（30%）**：
- 行业第 1 → 100 分
- 行业第 2-3 → 70 分
- 行业第 4 以后 → 40 分

**护城河定性判断（30%）**：
评估以下任一项：
- 品牌溢价（消费者愿意多付钱）
- 规模优势（成本低于同行）
- 网络效应（用户越多越难替代）
- 专利/许可/行政壁垒
- 转换成本（客户换不掉）

每有一项 +25 分，最多 100 分

## 五、权重计算细则

### 5.1 原始权重计算

```
个股初始权重 = 个股综合评分 ÷ Σ(所有入选股综合评分)
```

### 5.2 单只约束调整（比例压缩法）

当最高初始权重超过10%上限时，**禁止将超限股票拍平到10%等权重**，改用**比例压缩法**：

1. 找出初始权重最高的股票 Wmax
2. 压缩因子 = 10% ÷ Wmax（最高那只刚好压到10%）
3. **所有股票的最终权重 = 初始权重 × 压缩因子**
4. 此时最高权重刚好10%，其余股票按比例低于10%

**示例**：10只入选股，评分从87.3到69.4
- 格力初始权重11.45%（最高），压缩因子 = 10%/11.45% = 87.31%
- 格力最终权重 = 10.0% ✅、西藏 = 9.18%、华润江中 = 9.04%、伟星新材 = 7.95%
- ✓ 优股多配、评分低的少配，体现评分加权

### 5.3 行业约束调整

若某行业总权重 > 20%，行业内按股息率比例等比例压缩，直至≤20%。

### 5.4 最终权重校验

```
组合加权股息率 = Σ(个股股息率 × 个股归一化权重)
组合加权ROE = Σ(个股ROE × 个股归一化权重)
组合加权负债率 = Σ(个股负债率 × 个股归一化权重)
```

> ⚠️ **关键规则**：个股归一化权重 = 个股最终权重 ÷ Σ(所有入选股最终权重)。
> 因为最终权重是占总仓位的比例（总和<100%），计算组合指标时必须归一化到"买入资金池"（总和=100%）。
> 现金不产生股息和不计入ROE，所以组合加权指标只应考虑实际投入股票的那部分资金。

## 六、调仓逻辑

### 6.1 定期调仓（每季度）
- **1 月**：年报预告后初步评估
- **4 月底**：年报出完，正式调仓
- **8 月底**：半年报出完，检查调整
- **10 月底**：三季报出完，检查调整

### 6.2 特殊调仓条件（随时触发）

**无条件卖出（必须清仓）**：
- 持仓股股息率跌破 2.5%（股价大涨透支股息）
- 持仓股出现重大财务风险信号
- 持仓股 ROE 连续 2 年 < 8%
- 持仓股被 ST 或审计非标
- 触发一票否决中的任何一项

**条件性减仓（降低权重）**：
- 单行业超 20% 上限 → 按股息率从低到高依次减仓，直至达标
- 某只股票因股价大涨导致当前股息率降至 3%-4.0%区间 → 减半仓
- 某行业基本面恶化（政策打压、需求下滑）→ 该行业所有股票减至半仓

### 6.3 减仓方案输出要求
每次定期调仓或特殊调仓时，报告必须包含以下减仓信息：

1. **强制调出清单**：逐只列出触发卖出条件的股票，说明触发了哪项规则、具体数值
2. **建议减仓清单**：逐只列出权重偏高或股息率下降的股票，说明建议减仓幅度和原因
3. **减仓优先级排序**：按风险程度从高到低排列
4. **释放资金去向**：减仓释放出来的资金如何分配（买入新标的或转为现金储备）

### 6.4 换手率限制
- 单次调仓换股不超过持仓总数的 30%
- 目的是降低交易摩擦和税务成本
- 减仓逻辑优先于加仓逻辑：先卖该卖的，再用资金买新的

## 七、数据获取指引

### 7.1 妙想（mx-data）常用查询语法

```
# 单只股票基本面数据
查询 [股票代码] [年份] 的 [指标列表]，如：
- "查询 600519 2024 年的 ROE、资产负债率、毛利率"
- "查询 600519 近 5 年的每股分红数据"
- "查询 000651 2023-2025年报 经营活动产生的现金流量净额/净利润"  # 直接返回净现比！

# 批量筛选（推荐用mx-xuangu）
"筛选 A 股中股息率TTM大于 4.0% 的股票"
"筛选食品饮料行业中股息率TTM大于 4.0% 的股票"
"筛选 A 股中股息率TTM大于 5% 且资产负债率小于 70% 的股票"

# 行业数据
"查询 [行业] 的龙头企业列表及股息率"
"查询市盈率历史百分位 [股票代码]"
```

### 7.2 数据获取优先级
1. mx-xuangu（全市场多条件初筛）→ mx-data（逐只补查）→ mx-moni（监控）
2. 优先使用结构化 API 数据，其次才用文章搜索
3. 数据缺失时标注"数据不可用"，不猜测

### 7.3 ⚠️ 现金流数据强制规则（最重要）

**净现比（经营现金流/净利润）数据必须使用 mx-data 年报数据，严禁使用季度数据评分。**

**原因**：季度与年报的净现比差异极大，典型失真案例：

| 股票 | 季度（mx-xuangu） | 年报（mx-data） | 偏差倍数 |
|:----:|:-----------------:|:---------------:|:--------:|
| 达仁堂 | 99.6% | 21.8% | 4.6x ❌ |
| 宇通客车 | 529.9% | 56.8% | 9.3x ❌ |
| 索菲亚 | 736.9% | -34.1% | 符号相反 ❌ |
| 泸州老窖 | 122.5% | 65.6% | 1.9x ❌ |

**执行流程**：
1. mx-xuangu 季度净现含金量 → **仅用于初筛**（排除明显负值）
2. mx-data 年报直接查询：`"查询[代码]2023-2025年报 经营活动产生的现金流量净额/净利润"`
   → **直接返回计算好的净现比**，无需手动计算
3. 连续3年均 ≥ 80% 方可通过量化门槛
4. 评分时使用**3年净现比平均值**

## 八、设计思想

本框架融合以下理念：

| 思想来源 | 在本框架中的体现 |
|----------|-----------------|
| **巴菲特·所有者导向** | ROE ≥ 10%、经营现金流 > 80%、重视护城河 |
| **格雷厄姆·防御型选股** | 低负债率、连续分红历史、估值安全边际 |
| **段永平·本分/做对的事** | 行业龙头、稳定盈利、不投看不懂的 |
| **唐朝·财报排雷** | 审计意见、现金流验证、排除财务风险 |
| **中证红利编制规则** | 连续分红、股利支付率限制、行业分散 |
| **标普红利贵族思路** | 分红稳定不下降（方案 A） |
