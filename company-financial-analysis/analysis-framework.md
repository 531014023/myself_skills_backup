# 企业财务分析框架

> 源自唐朝《手把手教你读财报2021(新准则升级版)》  
> 结合巴菲特、芒格投资理念

---

## 一、资产负债表速读框架

### 1.1 先看负债和所有者权益

**第一步**：看"负债和所有者权益总计"，知道公司总家当  
**第二步**：看"所有者权益合计"，知道多少是自己的，多少是借来的  
**第三步**：负债率用 **有息负债÷总资产**，不用负债÷总资产（无息负债无压力）

**警戒线**：有息负债率 ≥ 60% → 激进，多一份小心

### 1.2 再看资产项目——四个关键比值

拿到资产总计数据后，重点看四个比值，从三个角度观察：**结构、历史、同行**。

#### (1) 生产资产 ÷ 总资产 → 轻重资产判断

- 生产资产 = 固定资产 + 在建工程 + 工程物资 + 无形资产中的土地
- 占比大 = 重资产公司；占比小 = 轻资产公司
- **轻/重判据**：当年税前利润总额 ÷ 生产资产
  - 显著高于社会平均资本回报率（银行贷款标准利率×2）→ 轻资产
  - 低于 → 重资产
- 重资产公司：需不断投入维护更新，折旧吞噬利润
- 轻资产公司：回避高固定成本，逆境中更具韧性
- **历史分析**：观察生产资产/总资产比例如何变化，思考变重/变轻的原因

#### (2) 应收 ÷ 总资产 → 回款健康度

- 应收 = 所有"应收"科目总和 - 银行承兑汇票金额
- **比例**：超过三成算严重
- **突变**：应收增幅不应超过营收增幅
- **异常**：单独测试减值为零、集中在关联企业、其他应收款突增

#### (3) 货币资金 ÷ 有息负债 → 偿债能力

- 稳健公司：货币资金 ≥ 有息负债
- 可放宽至：货币资金 + 可迅速变现金融资产 + 银票 ≥ 有息负债
- 刚性标准，不须同行对比

#### (4) 非主业资产 ÷ 总资产 → 专注度

- 非主业资产占比增加 → 管理层在行业内找不到好机会
- 包括：交易性金融资产、可供出售金融资产、投资性房地产、银行理财等

## 二、利润表速读框架

### 2.1 四个关键要点

| 要点 | 含义 | 判断标准 |
|------|------|---------|
| **营业收入** | 经营趋势 | 持续增长 > 行业平均；关注增长途径（需求/份额/提价） |
| **毛利率** | 产品竞争力 | ≥40% 有持续竞争优势；20%-40% 竞争激烈；<20% 谨慎 |
| **费用率** | 管理效率 | 费用/毛利润 ≤30% 优秀；30%-70% 尚可；>70% 价值不大 |
| **营业利润率** | 盈利能力 | 越大越好，关注历史变化趋势 |

### 2.2 费用率计算规则

- 财务费用为正（净支出）→ 三费合计 ÷ 营业总收入
- 财务费用为负（净收入）→ (销售费用+管理费用) ÷ 营业总收入
- 2018年后研发费用单列 → 三费变四费

### 2.3 净利润含金量

**经营现金流净额 ÷ 净利润 ≥ 1** → 优秀企业的重要特征  
持续 > 1 = "印钞机"概率大；持续 < 1 = 利润质量存疑

## 三、现金流量表速读框架

### 3.1 八种现金流肖像

| # | 经营 | 投资 | 筹资 | 类型 | 核心关注 |
|---|:---:|:---:|:---:|------|---------|
| 1 | + | + | + | 妖精型 | 警惕资金转移 |
| 2 | + | + | - | 老母鸡型 | 低PE+高股息可投 |
| 3 | + | - | + | 蛮牛型 | 项目前景+资金链 |
| 4 | + | - | - | 奶牛型 | 可持续性（核心指标） |
| 5 | - | - | - | 大出血型 | 远离 |
| 6 | - | - | + | 赌徒型 | 风险极高 |
| 7 | - | + | - | 混吃等死型 | 区分变卖or分红 |
| 8 | - | + | + | 骗吃骗喝型 | 危险 |

### 3.2 奶牛型可持续判断（最重要）

经营现金流入 > 投资现金流出 + 筹资现金流出（不含分红）→ 可持续  
否则 → 可能变身蛮牛型

### 3.3 寻找优质企业的5组数据

1. 经营活动现金流净额 > 净利润 > 0
2. 销售商品、提供劳务收到的现金 ≥ 营业收入
3. 投资活动现金流出 > 投资流入（主要用于扩张，非维持）
4. 现金及现金等价物净增加额 > 0（可排除分红影响）
5. 期末现金及现金等价物余额 ≥ 有息负债

## 四、企业财务分析四步走

### Step 1: 科目异常检查

#### 资产端检查
- 应收账款、应收票据 → 增幅是否超过营收增幅
- 其他应收款 → 数额是否过大
- 长期待摊费用 → 占比是否过大

#### 负债端检查
- 应付票据、应付账款 → 是否大比例增长
- 其他应付款 → 是否异常
- 短期借款 → 是否大比例增长

#### 利润表检查
- 营业利润率 → 是否大幅波动
- 公允价值变动收益 + 投资收益 + 资产减值损失 → 占营业利润比例是否突变
- 营业利润与净利润比例 → 是否稳定

### Step 2: 财务指标历史分析

必须看满**5年以上**数据才能判断可信度。

ROE规律：公司上市当年ROE通常会较上市前3年平均下跌超50%，以后也难恢复。

### Step 3: 利润与现金流对比

拉长几年看，净利润总量与经营现金流净额总量应保持大致稳定比例，且最好经营现金流 > 净利润。

### Step 4: 与竞争对手比较

- 资产负债结构对比 → 行业内战略分歧或共识
- 利润表指标对比 → 管理层是否有效运用资源
- 避免被孤立增速迷惑（鸭子没随水面上升）

## 五、财务指标分析体系

### 5.1 安全性分析

**核心指标**：现金债务比

```
现金债务比 = 现金及现金等价物 ÷ 有息负债 ≥ 1
可放宽至：(现金+可迅速变现金融资产) ÷ 有息负债 ≥ 1
最保守：(现金+可迅速变现金融资产) ÷ 一年内到期有息负债 ≥ 1
```

**辅助指标**：
- 流动比率 = 流动资产 ÷ 流动负债（理想≈2）
- 速动比率 = (流动资产-存货) ÷ 流动负债（理想≈1）
- 资产负债率 = 负债总额 ÷ 资产总额
- 利息保障倍数 = (利息总额+利润总额) ÷ 利息总额

### 5.2 盈利能力分析

#### 收入视角
- **营业利润率** = 营业利润 ÷ 营业收入（最核心）
- 毛利率 = (营业收入 - 营业成本) ÷ 营业收入
- 净利率 = 净利润 ÷ 营业收入

#### 资产视角
- **净资产收益率 (ROE)** = 净利润 ÷ 平均净资产（巴菲特首选，>20%）
- 总资产收益率 (ROA) = 净利润 ÷ 平均总资产
- 净资产现金回收率 = 经营现金流净额 ÷ 平均净资产

### 5.3 成长性分析

- 营业收入增长率 = (本期营收 - 上期营收) ÷ 上期营收
- 营业利润增长率 = (本期营业利润 - 上期营业利润) ÷ 上期营业利润
- 资产增长率 = (本期资产 - 上期资产) ÷ 上期资产
- 净资产增长率 = (本期净资产 - 上期净资产) ÷ 上期净资产

### 5.4 管理层能力分析（营运能力）

- 应收账款周转率 = 营业收入 ÷ 平均应收账款
- 存货周转率 = 营业成本 ÷ 存货平均余额
- 固定资产周转率 = 营业收入 ÷ 固定资产净值
- 总资产周转率 = 营业收入 ÷ 平均总资产

## 六、ROE深度分析框架（杜邦体系+）

### 6.1 基础杜邦拆解

```
ROE = 净利润率 × 总资产周转率 × 权益乘数
    = (净利润÷营收) × (营收÷平均总资产) × (平均总资产÷净资产)
```

### 6.2 三种盈利模式

| 模式 | 核心驱动 | 代表 | 风险 |
|------|---------|------|------|
| 茅台模式 | 高净利润率 | 高端消费、品牌药企 | 替代品威胁 |
| 沃尔玛模式 | 高周转率 | 零售、快消 | 管理层依赖 |
| 银行模式 | 高杠杆 | 金融、地产 | 脆弱，一次意外归零 |

### 6.3 经济商誉推导

```
经济商誉 G = (ROE ÷ 无风险收益率N - 1) × 净资产A
```

- ROE越大，经济商誉越大
- ROE < 无风险收益率 → 经济商誉为负（价值毁灭）

### 6.4 ROE可持续性分析

必须结合以下维度判断ROE是否可持续：

1. **盈利质量**：经营现金流/净利润 是否持续>1
2. **杠杆水平**：权益乘数是否过度依赖债务
3. **利润率稳定性**：毛利率、净利率是否稳定或上升
4. **周转率趋势**：总资产周转率是否稳定或改善
5. **ROE来源**：是来自主业还是非经常性损益
6. **资本结构**：是否存在大量表外负债
7. **分红政策**：高ROE+低分红可能是资金利用效率高，也可能是无法分红（利润不真实）

### 6.5 ROE深度拆解（五层穿透）

```
第一层: ROE = 净利润 ÷ 净资产
第二层: ROE = (净利润÷营收) × (营收÷总资产) × (总资产÷净资产)
第三层: 净利润率 = (毛利-三费-减值±投资±公允-税) ÷ 营收
        = 毛利率 - 费用率 - 减值损失率 - 税率 ± 其他
第四层: 总资产周转率 = 营收 ÷ (流动资产+非流动资产)
        → 分解为各项资产周转率
第五层: 权益乘数 = 1 ÷ (1-资产负债率)
        → 有息负债 vs 无息负债拆分
```

## 七、异常排查清单

### 资产负债表红灯

| 信号 | 含义 |
|------|------|
| 应收账款增幅 > 营收增幅 | 放松信用政策/虚增收入 |
| 应收占总资产 > 30% | 回款风险高 |
| 货币资金/有息负债 < 1 | 偿债能力不足 |
| 存贷双高 | 资金虚构/挪用/冻结 |
| 其他应收款数额大 | 经营不规范/资金占用 |
| 长期待摊费用大 | 资产质量差 |
| 在建工程迟迟不转固 | 避折旧或虚构工程 |
| 商誉占比过大 | 并购溢价风险 |
| 存货增长大幅超过营业成本增长 | 存货积压或造假 |
| 毛利率提升伴随存货大增 | 固定成本转存货（虚增利润） |
| 应收账款坏账计提标准突变 | 调节利润 |
| 固定资产折旧政策突变 | 调节利润 |
| 资产大额减值后次年出售 | 操纵报表（减值不可转回但卖出可确认利润） |

### 利润表红灯

| 信号 | 含义 |
|------|------|
| 毛利率异常波动无合理解释 | 竞争力变化或造假 |
| 费用率剧烈变化 | 费用调控 |
| 资产减值损失经常大额正负 | 调节利润 |
| 营业外收支占比过大 | 主业不清晰 |
| 净利润含金量持续<1 | 纸面利润 |
| 连续数年微利后突然巨亏 | 洗大澡 |
| 销售费用激增但营收不增 | 产品推力不足 |

### 现金流量表白灯

| 信号 | 含义 |
|------|------|
| 经营现金流持续为负 | 入不敷出 |
| 经营现金流为正但主要靠应付增加 | 拖欠供应商（资金链信号） |
| 投资购建支出持续>经营现金流 | 借钱扩张（关注资金来源） |
| 大量出售固定资产带来投资现金流入 | 经营衰败 |
| 取得借款远小于归还借款 | 银行"骗还贷"（严重信号） |
| 筹资支付异常高利息 | 生存危机 |
| 经营现金流净额/净利润突然大幅波动 | 利润质量突变 |

### 行业高危区

- 农林渔牧 → 生物资产难盘点
- 软件/集成电路 → 税收优惠多，产品差异大
- 生物科技 → 产品不易核查
- 以上行业需**格外警惕**，造假成本低
