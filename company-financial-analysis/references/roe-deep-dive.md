# ROE深度分析框架

> 超越杜邦三因素的 ROE 五层穿透分析法

---

## 第一层：ROE本身

```
ROE = 归母净利润 ÷ 平均归母净资产
```

**判断标准**：
- ROE ≥ 20%：巴菲特选股标准，优秀
- ROE 15%-20%：良好
- ROE 10%-15%：一般
- ROE < 10%：需关注
- ROE < 无风险收益率：价值毁灭

**关键观察**：
1. ROE趋势是上升还是下降？
2. 是否有大起大落？（可能是非经常性损益影响）
3. 上市当年ROE是否大幅下跌？（常见化妆后遗症）

---

## 第二层：杜邦三分解

```
ROE = 净利润率 × 总资产周转率 × 权益乘数
```

### 三种驱动模式识别

| 模式 | 净利润率 | 周转率 | 杠杆 | 代表 |
|------|:------:|:-----:|:---:|------|
| 茅台模式 | 高(>20%) | 中 | 低 | 高端品牌消费 |
| 沃尔玛模式 | 低(<10%) | 高(>1.5) | 中 | 零售快消 |
| 银行模式 | 中 | 低 | 高(>3) | 金融地产 |
| 混合型 | 中(10-20%) | 中 | 中 | 制造业 |

### 趋势分析
- 三个因子历年变化方向
- 哪个因子是ROE变化的主驱动？
- 驱动力的可持续性？

---

## 第三层：净利润率拆解

```
净利润率 = 毛利率 - 费用率 - 资产减值损失率 - 税率 + 其他
```

### 毛利率分析
- 历史趋势：稳定上升 = 竞争力增强
- 与同行对比：显著高于同行 = 护城河
- 大幅波动原因：提价？成本变化？产品结构？
- 毛利率提升伴随存货大增 → 🚩虚增利润信号

### 费用率分析
- 三费/营收 历史趋势
- 销售费用率：高 = 产品推力不足
- 管理费用率：上升 + 营收不增 = 管理效率下降
- 财务费用率：正 → 有债务负担；负 → 有净利息收入
- 研发费用率：高 → 技术依赖型（风险）
- 费用/毛利 ≤ 30% → 优秀；30-70% → 尚可；>70% → 价值不大

### 非经常性项目
- 公允价值变动 + 投资收益 + 资产减值 三者和占营业利润比例
- 若占比>20%或大幅波动 → 利润质量存疑

---

## 第四层：资产周转率拆解

```
总资产周转率 = 营收 ÷ 平均总资产

可以分解为：
应收账款周转率 = 营收 ÷ 平均应收账款
存货周转率 = 营业成本 ÷ 平均存货
固定资产周转率 = 营收 ÷ 固定资产净值
```

### 判断要点
- 总资产周转率趋势：上升 → 效率提升；下降 → 资产变重
- 应收账款周转率下降 → 🚩信用政策放松或虚增收入
- 存货周转率下降 → 产品积压
- 固定资产周转率：判断轻重资产

---

## 第五层：权益乘数拆解

```
权益乘数 = 总资产 ÷ 净资产 = 1 ÷ (1 - 资产负债率)
```

### 杠杆质量分析
```
有息负债率 = 有息负债 ÷ 总资产
无息负债率 = (总负债 - 有息负债) ÷ 总资产
```

- 高杠杆但主要是无息负债（应付/预收）→ 产业链强势，良性
- 高杠杆且主要是高息负债 → 🚩财务风险
- 有息负债率 > 60% → 激进
- 货币资金/有息负债 < 1 → 偿债风险

---

## ROE可持续性综合检查

| 维度 | 健康信号 | 危险信号 |
|------|---------|---------|
| 盈利质量 | 经营现金流/净利润 ≥ 1 | 持续 < 1 |
| 杠杆水平 | 权益乘数 ≤ 3 且以无息负债为主 | 权益乘数 > 5 或有息负债率 > 60% |
| 利润率 | 毛利率稳定或上升 | 毛利率持续下滑 |
| 周转效率 | 总资产周转率稳定或改善 | 持续下降 |
| 利润来源 | 主要来自营业利润 | 依赖非经常性损益 |
| 分红政策 | 有持续分红能力 | 高ROE但几乎不分红（利润可能不真实） |
| ROE趋势 | 稳定或缓升 | 大起大落 |

---

## 经济商誉推算

```
经济商誉 G = (ROE ÷ 无风险收益率 - 1) × 净资产
```

- 无风险收益率建议取值：中国10年期国债收益率（约2.5-3.0%）
- G值越大 → 护城河越宽
- G值为负 → 企业摧毁价值
