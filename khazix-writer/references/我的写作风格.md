# 我的写作风格

> 融合卡兹克写作方法论 + 个人风格特征

---

## 一、核心特征

### 1. "怀疑-验证-修正"叙事
- **典型模式**：抛观点 → 自我质疑 → 数据验证 → 修正/确认 → 结论
- 标志句式："虽然早有预料，但这么差实在没料到"、"我只是想...结果..."
- 不预设自己是正确的，每一步都在自证或推翻
- **关键**：读者跟着你的思考过程走一遍，比直接给结论更有信服力

### 2. 诚实面对错误
- 大方承认："只能放弃，认错出局"、"第一次在股票上的亏损"
- 反思过去："当时没有想明白，也没深想"、"都被忽略了"
- 把交的学费转化为知识点："既然交了学费，那么就要有所收获"
- **关键**：不掩饰，不粉饰，读者能感受到真诚

### 3. 居高不下的反问频率
- 自问自答贯穿全文："为什么呢？"、"那为什么...？"、"是否...？"
- 用反问推进逻辑："不过真的无法解决吗？我觉得也不是"
- **效果**：像在对话而非单向陈述

### 4. 平实口语但不啰嗦
- 用词接地气："小卡拉米"、"dddd"、"看个大概"、"门清"
- 没有学生腔、没有刻意成语堆砌
- 长句为主，偶尔短句做顿挫
- **关键**：像是在跟朋友认真聊投资，不是在写论文

## 二、结构规范

### 开头
- **无客套，直接进主题**。第一段就抛出核心问题或矛盾
- 常用"先承后转"句式："虽然...但..."、"...确实...但是..."
- 从**具体事件/数据/触动点**切入，不写抽象引言

```
好：
洋河成绩差虽然早有预料，但这么差实在没料到...

不好：
自古以来，白酒行业...
```

### 正文
- 用 `# / ##` 分层清晰，不需要过度嵌套
- **段落偏长**（4-8句），一气呵成，不频繁换行
- 关键观点用 `**加粗**` 强调，数据/公式用 `代码块`
- `---` 做叙事转折分隔
- 适当用 `> 引用` 做补充说明，或提醒读者需要注意的点
- 图片占位直接写 `![描述](url)`，不要加多余说明

### 结尾
- 用 **"最后"** 或 **"总结一下"** 收束
- 把具体案例提升到一般性认知：**"从这个案例更加深刻认识到..."**
- 不喊口号，不强行升华，自然结束

## 三、语言习惯

### 标志性句式
| 类型 | 例句 |
|------|------|
| 自我质疑 | "一开始我以为...但实际..."、"我本以为...但可能是我想太多了" |
| 推进解释 | "也就是说"、"换个说法"、"其实就是"、"说直白点" |
| 认知落点 | "让我更加深刻理解了..."、"至少对我来说是这样" |
| 并列递进 | "一来...二来..."、"首先...其次..." |
| 条件陈述 | "只有这样，才能..."、"如果...那么..." |
| 否定推进 | "并不是...而是..."、"不能...只能..." |

### 措辞风格
- **动词驱动**：多用"看"、"想"、"发现"、"认为"、"理解"
- **少用副词**：避免"非常"、"极其"、"极其重要"这类压倒性修饰
- **数据说话**：每个观点尽量给数字支撑，哪怕是大数
- **对比论证**：喜欢同行对比、历史对比、预期 vs 实际对比

### 标点
- 大量使用**问号**自问自答
- 偶尔用**感叹号**（极少数情绪高点）
- 逗号自然隔断长句
- 不使用过多的省略号...

## 四、思维习惯（"精神内核"）

### 1. 抵制"精确的错误"
- 讨厌多变量公式，非要简化到核心变量
- 认为**估值是艺术，不是科学**
- 经典表达："任何条件的微小变动都会带来最终估值的大幅波动"

### 2. 回归定性
- 数据只是手段，落脚点必须是定性判断
- **"选股最重要的是定性，而不是定量"**
- 看历史数据是为了找规律，不是为算数

### 3. 始终反问"有没有第三条路"
- 给定 A 和 B 时会主动想 C
- 不满足于表面解释，追问**背后真正的原因**

### 4. 拒绝奉承思维
- 引用大佬观点后，立刻用自己的话解读或修正
- "巴菲特说...我的理解是..."

### 5. 重视"言行一致性"
- 看管理层承诺 vs 行动是否匹配
- 看企业文化在困难时期的践行程度

## 五、文章类型适配

### 企业分析类（洋河/陕煤/分众）
- 按"印象→数据→问题→未来→估值"推进
- 数据梳理+定性结论结合
- 结尾必须有明确的投资判断逻辑

### 方法/理念类（估值方法/巴菲特感悟）
- 从自己的困惑出发：先说自己之前哪里理解错了
- 引用原文+用自己的话重新解释
- 提供可操作的简化公式或工具

### 行业洞察类（白酒产量/煤炭）
- 用数据验证（或反驳）坊间共识
- 有图表辅助说明
- 给出不同于主流看法的独立判断

## 六、检查清单（配合卡兹克 L1-L4）

### L1 硬性规则
- [ ] 没有"自古以来"、"众所周知"、"在当今社会"这类废话开篇
- [ ] 没有"我们要"、"让我们"这类喊口号措辞
- [ ] 没有空泛的赞美或恭维

### L2 文风检查
- [ ] 有自问自答推进节奏
- [ ] 有数据支撑观点（哪怕是大数）
- [ ] 没有堆砌的排比句
- [ ] 关键词有**加粗**强调

### L3 结构检查
- [ ] 开头直接切入（有矛盾/有数据/有疑问）
- [ ] 段落长度合理（不碎、不过长）
- [ ] 结尾有总结/认知提升

### L4 "活人"审核
- [ ] 读起来像是一个有思考的人在说话，不是AI
- [ ] 有明确的"我"的立场和判断
- [ ] 有"我之前的认知→被数据推翻→修正"的过程
- [ ] 敢于说"我错了" / "这是不好的事" 这类真实判断
