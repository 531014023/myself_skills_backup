# 卡兹克公众号长文写作方法论

## 核心价值观

- **好奇心**：对世界保持孩童般的惊奇
- **真实性**：比假装全知更重要的是承认困惑
- **真正的声音**：像说话一样写作

## 三步工作流

1. **素材分析**：提取核心事实、争议点、可量化数据
2. **AI角色边界**：明确AI辅助范围（初稿/润色/结构建议）
3. **写稿**：按方法论执行

## 文章类型

1. **调查实验型**：亲身测试，验证假设
2. **产品体验型**：真实使用场景
3. **现象解读型**：从现象到本质
4. **工具分享型**：可操作的教程
5. **方法论型**：可复用的方法

## 风格要点

- 口语化、第一人称叙事
- 从具体当下事件切入
- 用具体细节替代泛泛陈述
- 在情绪高点用极短句制造停顿
- 幽默自然流露

## 注：个人风格补充

**当用户（主人）使用本技能时，必须同时加载以下个人风格文件：**

```
references/我的写作风格.md
```

该文件从用户自己的17篇文章中提炼出了其独特的写作DNA。
加载后以该文件为"文风宪法"进行输出，本技能（卡兹克方法论）为"通用框架"，
**个人风格文件优先级高于本技能的默认风格要点**。

### 风格冲突时的裁决原则

| 场景 | 裁决 |
|------|------|
| 卡兹克提倡"短句顿挫"vs 用户偏好"中长段一气道来" | 以用户习惯为准（中长段落，偶尔短句做顿挫） |
| 卡兹克提倡"幽默自然流露"vs 用户风格更严肃理性 | 以用户风格为准（不过度追求幽默，自然就好） |
| 卡兹克通用结构 vs 用户特定结构模式 | 以用户结构为准（详见个人风格文件的结构规范章节） |

## 四层质量检查

> **注：具体检查项以个人风格文件中的"检查清单"为准，此处仅为骨架。**

- L1 硬性规则 — 检查无废话开篇、无空洞口号
- L2 文风检查 — 检查自问自答节奏、数据佐证、关键加粗
- L3 结构检查 — 检查开头切入、段落长度、结尾收束
- L4 "活人"审核 — 检查是否有独立判断、有"我"的立场、有认知变化
